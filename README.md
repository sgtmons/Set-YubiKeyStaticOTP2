# Set-YubiKeyStaticOTP_GUI.ps1

A PowerShell GUI to write static OTP passwords to YubiKey slots using `ykman`.

## Features
- GUI-based password input
- Real-time log display
- Device Info display
- Security and input validation
- Version checking and update handling (coming soon)

## Usage
Download the latest `.ps1` script and run with PowerShell. Ensure `ykman` is in your system PATH.

## Requirements
- YubiKey Manager CLI (`ykman`)
- Windows PowerShell
